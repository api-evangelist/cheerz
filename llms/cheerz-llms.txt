# Cheerz

> Cheerz is a French direct-to-consumer photo-printing brand: customers pick photos from their
> phone camera roll or a connected cloud gallery in the Cheerz app or on cheerz.com, and Cheerz
> prints and ships the result as photo prints, fridge magnets, photo books and albums, wall
> canvases, framed prints, calendars, puzzles, greeting cards and the branded Cheerz Box. Founded
> in Paris in 2012 (legal entity Printklub), backed by Serena Capital and Iron Capital, and
> acquired by the German photo-finishing group CEWE Stiftung & Co. KGaA in February 2018 for
> around EUR 45 million. Cheerz continues to operate as CEWE's Paris site.

## There is no Cheerz API

Cheerz publishes **no public API, no developer portal, no SDK and no machine-readable contract**.
An agent cannot integrate with Cheerz programmatically. Verified on 2026-08-17:

- `https://www.cheerz.com/openapi.json` — 404. Same for `/openapi.yaml`, `/swagger.json`,
  `/api-docs` (see below), `/docs`, `/api`, `/graphql`, `/developers`, `/developer`.
- No `api.`, `developer.`, `developers.`, `docs.`, `partners.`, `status.`, `pro.` or `mcp.`
  subdomain of cheerz.com resolves in DNS.
- All 14 `/.well-known/*` probes across www.cheerz.com and support.cheerz.com returned 404 —
  no security.txt, no openid-configuration, no api-catalog, no A2A agent card.
- The 418-URL English sitemap and the 464-URL French sitemap contain only products, categories,
  collections, blog posts and four legal pages. No developer or API page exists in either.
- No first-party client library exists on npm (0 search results for "cheerz"), PyPI (404),
  RubyGems (404) or Packagist.
- `https://www.cheerz.com/api-docs` **does** return HTTP 200, and it is a trap: it is the
  Google-OAuth sign-in screen for the internal "Cheerz Admin" back office, not an API reference.
- `robots.txt` Disallows `/*/api/*`. That path is the private JSON backend the Cheerz SPA and
  mobile apps call. It is undocumented, unversioned, unauthenticated to third parties and not
  offered for integration. Do not treat it as an API surface.

Partnership, bulk-order and affiliate enquiries go through a human channel — the contact form and
the help centre — not through a developer programme.

## Products

- Photo prints in multiple formats, with optional coloured borders and finish choices
- Fridge magnets, including writable variants
- Photo books and albums (hardcover, softcover, DIY/scrapbook, mini)
- Wall decor: canvases (classic and retro), framed prints, posters, pele-mele wall arrangements
- Calendars (A3/A4 portrait and landscape, 30x45, advent calendars)
- Greeting and invitation cards, including a photo-and-video card
- Puzzles
- Cheerz Box and Memory Box gift formats
- Gift cards and promo codes

## GitHub

The `cheerz` GitHub organisation (created 2012-09-27, Paris, 25 public repositories) publishes no
API tooling. Its public repos are forks and internal helpers: Ansible roles (Datadog, Redis,
ImageMagick), Helm/GitHub Actions plumbing, iOS and Android libraries (Caishen payment card UI,
MockSwift, scissors image cropping, android-PageFlip, kotlin-media-manager), web libraries
(angular-payments, webfontloader, KineticJS) and style guides. No OpenAPI, no API client, no SDK.
